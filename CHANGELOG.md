## [0.1.0] - 2026-09-03

First public beta.

### Added

- Tree-sitter parse, fail-closed symbol resolution, and semantic analyzers
  (Fastify, SQL, KafkaJS, constructor DI, conditional factories)
- CodeTracr-owned `codetracr-graph.json` (no external graph backend)
- Local HTTP API and UI for lineage, flow, sequence, and blast radius
- Fixture POCs and golden tests under `packages/engine`
