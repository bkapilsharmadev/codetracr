# `@codetracr/server`

Local HTTP API and static UI host for a CodeTracr graph.

It does not parse source. It reads `codetracr-graph.json` produced by `@codetracr/engine`.

```powershell
npm run generate
npm run build
npm start
```

See [docs/getting-started.md](../../docs/getting-started.md) and [docs/api.md](../../docs/api.md).
